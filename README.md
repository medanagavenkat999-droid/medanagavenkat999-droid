## 🚀 Featured Projects

### 🩺 Diabetes Prediction System
An end-to-end machine learning web app that predicts diabetes from medical inputs such as glucose, BMI, blood pressure, insulin, and age. It uses a Random Forest Classifier trained on the Pima Indians Diabetes Dataset (80:20 split), with missing values handled through mean/median imputation. The model is saved with Pickle and served through a Flask app for real-time predictions.

**Tech Stack:** `Python` `Flask` `Scikit-learn` `Pandas` `NumPy` `HTML` `CSS`
🔗 [View Repository](https://github.com/medanagavenkat999-droid?tab=repositories)

### 🛒 Online Retail Sales Analytics (SQL)
A normalized MySQL database (customers, products, orders, order items) built from raw retail transactions. It uses multi-table JOINs, GROUP BY, HAVING, and correlated subqueries to find loyal customers, above-average spenders, and monthly revenue trends. Reusable SQL views (customer summary, monthly sales, top products) simplify reporting.

**Tech Stack:** `MySQL` `SQL` `Joins` `Subqueries` `Views` `MySQL Workbench`
🔗 [View Repository](https://github.com/medanagavenkat999-droid?tab=repositories)

### 📊 HR Analytics Dashboard
An interactive Power BI dashboard analyzing employee attrition, demographics, job roles, education, salary hikes, and workforce trends. It includes KPI cards for total employees, attrition rate, average age, and average salary, plus visuals that reveal attrition patterns by age, education, job role, and tenure.

**Tech Stack:** `Power BI` `DAX` `Data Visualization` `KPI Reporting`
🔗 [View Repository](https://github.com/medanagavenkat999-droid?tab=repositories)

### 📈 E-Commerce Sales Analysis
Interactive Pivot Tables and charts built in Excel to analyze sales performance, profit, and product trends to support business decisions.

**Tech Stack:** `Advanced Excel` `Pivot Tables` `Power Query` `Charts`
🔗 [View Repository](https://github.com/medanagavenkat999-droid?tab=repositories)
